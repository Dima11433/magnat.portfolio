# 🚀 Современное портфолио Frontend-разработчика

Стильный, быстрый и отзывчивый персональный сайт-портфолио на русском языке с дизайном в стиле Cyber-Glassmorphism, неоновыми градиентами, микро-анимациями и интерактивными возможностями.

---

## ⚡ Как запустить сайт

### Вариант 1: Самый простой
Просто откройте файл `D:\magnatsyka\index.html` двойным кликом в любом браузере (Chrome, Edge, Firefox, Opera, Yandex).

### Вариант 2: Локальный сервер через Python
Откройте терминал (PowerShell / CMD), перейдите в папку и запустите сервер:
```bash
cd D:\magnatsyka
python -m http.server 8000
```
Затем перейдите в браузере по адресу: [http://localhost:8000](http://localhost:8000)

## 🛠 Возможности и разделы сайта

1. **Шапка и Навигация**:
   - Фиксированный размытый бар (`backdrop-filter`) с индикатором прокрутки
   - Мобильное адаптивное меню-гамбургер
   - Плавный скролл к разделам
2. **Главный экран (Hero)**:
   - Статус-бейдж «Доступен для новых проектов» с пульсирующим индикатором
   - Интерактивная карточка разработчика с парящими бейджами технологий
   - Ключевые метрики (опыт, проекты, соблюдение сроков, PageSpeed)
3. **Обо мне и преимущества**:
   - 4 ключевых принципа работы (скорость, адаптивность, pixel-perfect, архитектура)
4. **Стек навыков**:
   - Группировка по категориям: Frontend, Инструменты, Дизайн & Вёрстка
   - Индикаторы владения технологиями
5. **Проекты с интерактивной фильтрацией**:
   - Фильтры по категориям (Магазины, Сайты, Приложения, Лендинги)
   - Кнопка «Подробнее» открывает модальное окно с полным описанием и списком фич
6. **Цитаты и мотивация (Дэвид Гоггинс)**:
   - Карточки с цитатами о дисциплине и преодолении
   - Интерактивная кнопка «⚡ Другая цитата» для генерации случайных мыслей
7. **Роадмап целей**:
   - Таймлайн текущих и запланированных целей с бейджами статуса
8. **Контакты и форма**:
   - Кликабельные карточки соцсетей (Telegram, Email, GitHub, Discord) с копированием в буфер обмена в 1 клик
   - Интерактивная форма обратной связи с анимацией и уведомлениями (Toast)
9. **Кнопка «Наверх»**:
   - Плавающая кнопка с круговым SVG индикатором прогресса чтения страницы

## 🎨 Как настроить под себя

- **Имя и описание**: Откройте `index.html` и замените имя «Даниил Шейко» на ваше.
- **Контакты**: В секции `#contact` замените `@developer_telegram`, email и ссылку на GitHub на ваши настоящие данные.
- **Фотография**: Чтобы использовать ваше настоящее фото, положите его в `assets/images/my-photo.jpg` и в `index.html` замените `assets/images/avatar.svg` на `assets/images/my-photo.jpg`.
- **Проекты**: Тексты и ссылки проектов можно отредактировать в `index.html` и в массиве `projectData` в `js/main.js`.
